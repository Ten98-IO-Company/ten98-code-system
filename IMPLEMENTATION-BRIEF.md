# Shared feature library

Use these maintained sources before implementing or adopting a repeated feature:

- [Feature catalogue](features/catalog.json): supported stacks, implementation entrypoints, release inputs and known gaps.
- [Adoption guide](docs/FEATURE-ADOPTION.md): complete source closure, provenance, integration and behavior checks.
- [Architecture contract](architecture.json): canonical versions, dependency profiles and shared package pins.
- [Contributor instructions](AGENTS.md): ownership, engineering standards, bounded work and required verification.

Track defects, adoption and historical validation in the [Issues](https://github.com/Ten98-IO-Company/ten98-code-system/issues) and [Project](https://github.com/orgs/Ten98-IO-Company/projects/1). This existing entrypoint remains available for older links; the adoption guide owns the workflow.
